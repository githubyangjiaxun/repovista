# v0.6 前端开发文档：Guardrails Workspace

## 1. 页面入口

Repository Workspace 左侧导航增加 `Guardrails`。URL 使用 `?tab=guardrails`，并保留当前
`repositoryId` 与 `snapshotId`，刷新后仍查看同一不可变 Snapshot。

## 2. 展示结构

1. 顶部显示 `pass / warn / fail`、Finding 数量、规则版本和 Commit 短 SHA。
2. 阈值卡片显示行数、字节数、符号跨度和扇入阈值；不允许在页面临时修改阈值。
3. Finding 列表按 error、warning、info 分组；每项显示规则、路径、行范围、指标和解释。
4. 有证据的路径/行号使用现有 Source Panel 打开，保持固定 Commit。
5. SARIF 下载使用认证 Fetch + Blob，私有仓库不通过匿名锚点请求。

## 3. 交互与可访问性

- 加载、空结果、Snapshot 未就绪和权限错误都有明确状态。
- Finding 使用语义化 `article`、标题和 `aria-label`；颜色不是唯一信息，必须同时显示文字级别。
- 页面不展示源码全文，只在用户点击证据后复用已有 Source Panel。
- 下载按钮在请求中禁用并显示进度；失败时使用统一错误横幅。

## 4. 测试

- Guardrails Panel：pass/warn/fail、Finding 点击、空结果、错误和 SARIF 下载。
- Repository Explorer：导航到 Guardrails、Snapshot 切换和私有下载 credentials。
- Playwright：至少覆盖一个含循环和大文件的确定性 Fixture；不依赖外部 GitHub。

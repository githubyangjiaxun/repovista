# v0.3 前端开发文档

## 页面

在现有 Repository Workspace 增加 `Impact` 标签和独立 `/repositories/{id}/pull-requests/{number}` 页面：

- PR header：编号、标题、URL、base/head 短 SHA、Parser/算法版本、分析状态。
- Change summary：added/modified/deleted/renamed 文件和符号计数，支持路径过滤。
- Impact map：直接/传递影响切换、风险等级过滤、最多 2,000 节点提示、最短路径展开。
- Evidence drawer：固定 Snapshot、Commit、路径、行号、关系类型、源码片段和“在 VS Code 打开”链接。
- Failure/limited 状态：GitHub 限流、快照构建、静态关系缺失、结果截断均给出可操作说明。

## 数据与交互

使用现有 `apiFetch` 和 React 状态；长任务通过 SSE/轮询加载，查询 key 必须包含 analysis id、revision、cursor、filter。切换页面时取消旧请求，避免旧 PR 结果覆盖新状态。所有外链使用 `https://github.com`，源码链接包含 snapshotId 与 commitSha。

## 可访问性与性能

影响表支持键盘焦点、ARIA 状态和高对比度风险色；首屏只加载摘要和前 50 条 impact，路径/源码按需加载。大图显示截断和分页，不在浏览器重算 BFS。

## Next.js 约束

修改 Next.js 前必须阅读仓库安装版本 `apps/web/node_modules/next/dist/docs/` 的相关文档；保持 Server/Client Component 边界，新增组件有 Vitest，关键旅程有 Playwright。

# v1.3 前端开发文档：Review 时间线与通知设置

## Review 时间线

- Finding 卡片增加 History 按钮；按需加载当前 Finding 的历史，默认不拉取全部时间线。
- 时间线显示状态变化、备注长度变化、操作者和 UTC 时间；明确提示备注正文不会进入历史/通知。
- 使用游标分页，过期请求由 Snapshot epoch 丢弃；加载失败显示 request ID，不覆盖当前 Review 草稿。
- Viewer 可查看历史但不能修改 Review；匿名公开页面不显示协作时间线。

## 通知设置

- Settings 增加 Notification Endpoints 面板：Owner 创建/编辑/启停/删除，Editor 可查看投递结果并发送测试事件。
- 创建成功时以一次性密码框显示 `signingSecret`，提供复制按钮和“已保存”确认；前端不写 localStorage、URL 或埋点。
- Endpoint URL、事件订阅和 enabled 状态通过共享 `apiFetch` 提交，Session mutation 自动带 CSRF。
- Delivery 表按状态显示 queued/running/succeeded/failed、尝试次数、HTTP 状态和下次重试时间。

## 安全与可访问性

- URL 和错误均以纯文本渲染；不使用 `dangerouslySetInnerHTML`。
- 所有按钮有明确 label，复制成功使用可读提示，加载状态使用 `aria-busy`，错误使用 `role=alert`。
- 不在浏览器执行 Webhook 请求或暴露服务端 master secret；签名只由 Worker 生成。

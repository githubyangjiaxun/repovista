# v1.3 人审、通知与 AI 可信边界

v1.3 仍然不把 Review 当作 AI 评分。Deterministic Guardrail、Verified Explanation、Human Review 和
Notification Outbox 是四个相互隔离的层：

| 层 | 来源 | 是否改变 Deterministic/AI 结论 |
|---|---|---|
| Deterministic analysis | Snapshot、Parser、Profile、固定算法 | 唯一决定 Finding/CI |
| Verified explanation | 服务端固定 prompt + 引用验证 | 不改变 Finding |
| Human review | Workspace 成员状态和备注 | 不改变 Finding/模型回答 |
| Notification | Review 变更的无敏感摘要 | 只负责传递事件 |

通知 payload 不含 Review 备注正文、源代码、完整 Finding JSON、模型 prompt/answer 或任何 API/模型凭据。
Webhook 失败不会改变 Review 状态；重试只影响投递状态。Review 备注也不会发送给模型，历史只保留状态和
长度变化。这样外部系统无法把通知误当成模型质量证明或 CI 结论。

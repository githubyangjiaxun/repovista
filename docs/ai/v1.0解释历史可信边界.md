# v1.0 AI 可信边界：解释历史与比较

状态：已实现并验收（2026-08-25）

## 1. 不新增模型调用

历史列表和比较只读取 v0.9 已经通过 citation verifier 的不可变解释。v1.0 不增加 Prompt、不发送
新的源码片段，也不要求模型评价旧答案。

## 2. 可以证明什么

- 两条记录属于同一 Workspace、Repository 和确定性 `subjectKey`；
- 每条记录固定到自己的 Snapshot、Commit、Profile、Provider、Model 和 Prompt；
- 哪些结构化字段完全相同，哪些发生变化；
- Citation 仍指向各自 Snapshot 中已经校验的路径、范围和 quote。

## 3. 不能证明什么

- 新解释是否比旧解释更准确、更安全或更有帮助；
- 文本变化是否由代码、模型版本、Prompt、Profile 或随机性单独导致；
- 两条解释覆盖了 Finding 的所有可能原因或修复方式。

因此 API 只返回 `same/changed`，不会返回 improved、regressed、score 或 winner。Guardrails 的确定性
Finding 和 SARIF 继续是 CI 权威结果。

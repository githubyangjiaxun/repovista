# v1.4 批量 Review、通知与 AI 可信边界

v1.4 不引入新的模型调用。批量 Review 是人类协作元数据，通知适配器只是确定性序列化层。

- Deterministic Guardrails 仍唯一决定 Finding、severity、threshold、报告状态和 CI 退出码。
- Verified Explanation 仍只消费服务端选择的固定证据；批量状态和备注不会进入 prompt，也不会改变引用验证。
- Generic/Slack payload 只含事件身份、Snapshot/Finding 身份、状态转移、note 长度/变化布尔值和操作者摘要。
- Slack blocks 不是模型生成文本；所有文案由服务端固定模板生成，未知字段被拒绝或丢弃。
- 适配器不执行用户代码、不加载远程模板、不把 Webhook 响应正文写入数据库。
- “已发送”只表示 HTTP 投递成功，不表示 Review 正确、Finding 已修复或 AI 结论可信。

验收只能证明 fake fetch、Schema 和安全策略；不能冒充真实 Slack 可用性或外部模型质量。

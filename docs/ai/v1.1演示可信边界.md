# v1.1 Demo AI 可信边界

状态：已完成验收（2026-08-27）

v1.1 的内置 Demo 会生成两条 Guardrail Explanation，但不会调用语言模型。它使用现有
`FakeModelProvider` 对服务端选出的有界 Evidence 做确定性摘要，再经过与外部 Provider 完全相同的
Citation verifier。

它能证明：

- Provider 请求之外的 Finding、Commit、Profile 和 Evidence 由代码控制；
- Citation 能回到固定 Snapshot 的真实源码行；
- 无效 Evidence ID 会被 verifier 删除；
- Explanation 幂等持久化、历史和结构比较可运行；
- 项目在没有模型 Key 时仍有完整可体验路径。

它不能证明：

- 某个外部模型的准确率、推理能力、延迟或成本；
- 自然语言解释比其他版本更好；
- Guardrail Finding 是安全漏洞或自动修复建议；
- 合成 Fixture 代表真实大型仓库性能。

UI、README、Smoke 输出和验收记录都使用 `deterministic demo provider`、`bundled fixture` 或
同等明确表述，不得只写“AI 已验证”。

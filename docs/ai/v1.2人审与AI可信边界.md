# v1.2 人审与 AI 可信边界

v1.2 的 Review 是人类协作元数据，不是 AI 结论，也不是对 Finding 严重性的重新判断。

## 明确分层

| 层 | 来源 | 是否影响 CI/Guardrail status |
|---|---|---|
| Deterministic analysis | 固定 Snapshot、Parser、Profile、算法 | 是，唯一来源 |
| Verified explanation | 可选模型 + 服务端引用验证 | 否 |
| Human review metadata | Workspace 成员的状态/备注 | 否 |

模型解释仍必须通过既有 evidence verifier；Review 不会绕过引用验证，也不会把 Fake Provider
包装为真实模型质量证据。导出同时标注 `deterministicStatus` 和 `reviewMetadataVersion`，消费方
必须分别处理两者。

审阅备注是用户输入，服务端限制长度、按纯文本保存和展示，不执行其中指令、不发送给模型，
也不写入审计原文。删除/修改成员不会把另一个 Workspace 的身份暴露给读取者。

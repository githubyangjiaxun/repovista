# v1.4 测试与发布计划

## 自动化矩阵

- Contracts：批量请求边界、Unicode note、适配器枚举、事件数组上限和响应重放。
- Notifications：Generic 原样、Slack payload、官方主机校验、凭据/Fragment/私网/重定向拒绝。
- Database：Migration 0011、批量全有或全无、并发相同/不同幂等键、未变化项不发通知、适配器快照。
- API：权限/CSRF/Demo/跨 Workspace、Finding 归属、Idempotency-Key 冲突、OpenAPI 对齐。
- CLI/Web：批量命令、adapter 参数、错误 request ID、Viewer 只读、键盘和 stale response。
- Worker：按快照渲染、签名保持一致、适配器失败不可重试、网络失败沿用退避。

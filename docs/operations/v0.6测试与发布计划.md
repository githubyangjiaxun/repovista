# v0.6 测试与发布计划

## 1. 自动化矩阵

| 层级 | 重点 |
|---|---|
| Guardrails unit | SCC 循环、阈值边界、未解析/失败解析、稳定 fingerprint |
| API | Access Check、ready gate、SARIF、缓存头、无源码泄露 |
| CLI | 默认摘要、JSON、SARIF 文件、退出码 2、错误脱敏 |
| Web | 页面导航、Finding 证据、下载、加载/空/错误状态 |
| Regression | OpenAPI、typecheck、全量测试、构建、Docker |

## 2. 质量门禁

```bash
pnpm openapi:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
docker compose config --quiet
docker compose build api worker web
git diff --check
git fsck --full
```

## 3. 对外声明边界

验收记录可以声明固定 Fixture 的规则结果、SARIF 可解析性和权限测试结果；不能把 Guardrails
描述为完整安全扫描、模型质量证明或真实 GitHub 外部联调，除非另行执行并记录对应环境。

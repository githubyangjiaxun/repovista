# v0.3 测试与发布计划

## 自动化门禁

1. OpenAPI operation 与 Fastify route 一一匹配。
2. 全 workspace Biome、Typecheck、Unit test、Build。
3. Parser fixture：Go package、struct/interface/method/import/call/embedding/module path；TS/JS/Python 回归。
4. Graph/Impact property tests：顺序稳定、边去重、BFS 深度/节点上限、风险分解和 unknown 证据。
5. PostgreSQL integration：Migration 0003、双快照不变量、幂等 key、事务回滚、分页游标、ready 不可变。
6. API/Worker：GitHub fixture、429/403、缺文件、重试/取消/租约丢失、SSE Last-Event-ID。
7. Web Vitest + Playwright：PR 创建、进度、双快照、影响筛选、证据 drawer、失败/截断/固定链接。
8. Extension host/mock：命令、TreeView、CSP、路径逃逸、Commit mismatch、离线缓存、`.vsix` 安装。

## 真实验收

- 公共 Go 仓库：记录 URL、完整 Commit、文件/符号/边统计和 Full → Incremental 计数。
- 脱敏 PR fixture：记录 number/base/head、文件变化、至少一条 direct 和 transitive path、风险分解和 Evidence hash。
- Compose：PostgreSQL/API/Worker/Web 启动、健康检查、容器 ARM64 build；扩展使用真实 API Origin 完成一次固定导航。

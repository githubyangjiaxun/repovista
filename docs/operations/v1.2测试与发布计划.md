# v1.2 测试与发布计划：Reviewable Guardrails

## 自动化矩阵

- Contracts：状态枚举、严格未知字段、备注长度、Reviewer nullable。
- Guardrails：SARIF review properties 不改变 level、数量或 deterministic status；输入顺序和
  review 顺序稳定。
- Database：Migration 0009、upsert/clear 并发、Workspace/Snapshot 隔离、审计元数据脱敏。
- API：匿名公开读取、Viewer 只读、Editor/Owner/Token 写入、CSRF、外部 Finding、Demo 写入、
  私有缓存头和稳定错误码。
- CLI：list/set/clear、`--json`、参数校验和非零错误码。
- Web/Playwright：加载、保存、清除、竞态保护和 Viewer 只读。
- OpenAPI：实现路由与文档一一对应。

## 发布门禁

```bash
pnpm openapi:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm benchmark
git diff --check
git fsck --full
```

Migration 只能前向增加，先在空 PostgreSQL 和已有 v1.1 数据库各执行一次。推送前必须
`git fetch origin`；如远端有提交，只做正常 rebase，禁止 force push。GitHub 仓库继续保持 Private。

# v0.9 测试与发布计划：Verified Guardrail Explanations

- `pnpm openapi:check`
- `pnpm lint`

- `pnpm test`

- `pnpm test:e2e`

- `docker compose build api worker web`

## 必测场景

- Fake Provider 成功解释并保存 citation。
- 非法模型 JSON、Provider 失败和空 Evidence。
- 不存在 Finding、非 Ready Snapshot、跨 Workspace 访问。
- 相同请求幂等复用；Provider/model/prompt 变化产生新记录。
- 数据库迁移后旧问答和旧 Snapshot 仍可读取。
- 私有缓存头、匿名公开 Demo、Viewer 只读行为。
- 浏览器 Finding 卡片成功、拒答、错误和竞态响应。

## 发布边界

不进行真实私有 GitHub 仓库或外部模型账户联调，不在验收记录中冒充通过。生产默认仍可关闭 AI Provider；关闭时既有确定性 Guardrails 和 SARIF 完全可用。

# v0.7 测试与发布计划

状态：已执行并验收（2026-08-23）

## 1. 自动化矩阵

| 层级 | 重点 |
|---|---|
| Guardrails compare unit | 稳定键、重复 Finding、状态分类、严重级别升降、排序和确定性 |
| API | 双快照权限、同仓库/Ready/Parser gate、兼容错误、缓存头和无源码 |
| CLI | compare 摘要、JSON、regressed 退出码 2、参数/网络错误 |
| Web | 基线选择、双侧证据、加载/错误/竞态和可访问性 |
| Regression | OpenAPI、lint、typecheck、全量测试、构建、E2E、Compose、Git |

## 2. 发布门禁

```bash
pnpm openapi:check
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
pnpm benchmark
docker compose config --quiet
docker compose build api worker web
git diff --check
git fsck --full
```

数据库集成测试未提供 `DATABASE_TEST_URL` 时必须明确记录 Skip，不能写成通过。真实 GitHub 外部
Fixture、模型服务和 SARIF 平台联调仍需专用环境。

## 3. 对外声明边界

验收记录可以声明固定两个 Snapshot 的比较结果、权限矩阵和可解析性；不能把基线比较描述为完整
安全扫描、架构正确性证明或自动合并阻断器。

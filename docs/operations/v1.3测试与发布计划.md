# v1.3 测试与发布计划：Review Timeline & Signed Notifications

## 自动化矩阵

- Contracts：历史游标、状态过滤、Endpoint URL/事件、严格未知字段和一次性秘密响应。
- Database：Migration 0001..0010、事务 outbox、幂等冲突、租约接管、重试状态和 Workspace FK。
- Notifications：签名向量、时间戳、退避、HTTP 状态分类、DNS/IP SSRF 拦截、重定向拒绝和超时。
- API：历史权限/隔离、Endpoint Owner/CSRF、测试投递、Delivery 分页和错误脱敏。
- Worker：成功、429/5xx 重试、4xx 终止、租约丢失、禁用 Endpoint 和下游不可达。
- CLI/Web：history、Endpoint CRUD/test、JSON、一次性秘密提示、时间线和 Viewer 只读。
- OpenAPI/E2E：实现路由与契约一致，固定 Demo 不可创建通知配置。

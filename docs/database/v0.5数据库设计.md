# RepoVista v0.5 数据库设计

状态：自动化开发与 PostgreSQL 验收完成（2026-08-22）
Migration：`0005_private_repository_auth.sql`

## 1. 设计原则

- 只追加 `0005`，不修改 `0001..0004`。
- Session/API/OAuth 原值不持久化，只保存固定长度 SHA-256 Hash。
- GitHub Installation ID 是外部身份，必须与 Workspace 一对一映射。
- 新表所有 Secret-free JSON 字段都有大小/形状的应用层验证。
- 审计数据是追加日志，业务路由不提供 Update/Delete Audit Event。

## 2. `user_identities`

| 列 | 类型 | 约束 |
|---|---|---|
| `id` | uuid | PK |
| `user_id` | uuid | FK users, cascade |
| `provider` | text | v0.5 只允许 github |
| `provider_user_id` | text | GitHub immutable numeric ID |
| `login` | citext | 当前 GitHub login |
| `profile_url` | text | HTTPS GitHub URL |
| `created_at/updated_at` | timestamptz | 时间 |

```text
UNIQUE(provider, provider_user_id)
UNIQUE(provider, login)
CHECK(provider_user_id ~ '^[1-9][0-9]*$')
```

Login 可变更，`provider_user_id` 是 Upsert 主键。

## 3. `oauth_login_states`

| 列 | 类型 | 约束 |
|---|---|---|
| `state_hash` | text | PK, `sha256:<64 hex>` |
| `return_to` | text | Web Origin 内相对路径 |
| `expires_at` | timestamptz | 必须大于 created |
| `created_at` | timestamptz | default now |

Callback 使用 `DELETE ... WHERE hash=$1 AND expires_at>now() RETURNING return_to`原子消费。定期删除过期行。

## 4. `auth_sessions`

| 列 | 类型 | 约束 |
|---|---|---|
| `id` | uuid | PK |
| `user_id` | uuid | FK users, cascade |
| `active_workspace_id` | uuid | FK workspaces, restrict |
| `token_hash` | text | unique SHA-256 |
| `csrf_token_hash` | text | SHA-256 |
| `expires_at` | timestamptz | 绝对过期 |
| `last_seen_at` | timestamptz | 节流更新 |
| `revoked_at` | timestamptz | nullable |
| `created_at` | timestamptz | default now |

复合 FK 保证 Active Workspace 是 User Membership：

```text
FOREIGN KEY(active_workspace_id, user_id)
  REFERENCES workspace_members(workspace_id, user_id)
```

因此需为 `workspace_members(workspace_id, user_id)` 现有 PK 直接复用。索引：

- `UNIQUE(token_hash)`
- `(user_id, created_at DESC)`
- `(expires_at) WHERE revoked_at IS NULL`

## 5. `api_tokens`

| 列 | 类型 | 约束 |
|---|---|---|
| `id` | uuid | PK |
| `workspace_id` | uuid | FK workspaces, cascade |
| `created_by` | uuid | FK users, cascade |
| `name` | text | 1..100 |
| `token_prefix` | text | 用于 UI 识别，不能认证 |
| `token_hash` | text | unique SHA-256 |
| `scopes_json` | jsonb | Scope 字符串数组 |
| `expires_at` | timestamptz | nullable，最长 365 天 |
| `last_used_at` | timestamptz | nullable，节流更新 |
| `revoked_at` | timestamptz | nullable |
| `created_at` | timestamptz | default now |

Token 必须由 Workspace Owner 创建。认证查询连接 `workspace_members(created_by, workspace_id)` 取得当前 Role，
不将创建时 Role 冗余到 Token。Owner 被移除/禁用后 Token 立即失效。

## 6. `github_installations`

| 列 | 类型 | 约束 |
|---|---|---|
| `installation_id` | bigint | PK, >0 |
| `workspace_id` | uuid | FK workspaces, cascade |
| `account_id` | bigint | GitHub Account ID >0 |
| `account_login` | citext | 展示 |
| `account_type` | text | User/Organization |
| `repository_selection` | text | all/selected |
| `permissions_json` | jsonb | Secret-free permission facts |
| `installed_by` | uuid | FK users, set null |
| `suspended_at` | timestamptz | nullable |
| `last_synced_at` | timestamptz | nullable |
| `created_at/updated_at` | timestamptz | 时间 |

```text
UNIQUE(workspace_id, installation_id)
INDEX(workspace_id, account_login)
CHECK(repository_selection IN ('all', 'selected'))
CHECK(account_type IN ('User', 'Organization'))
```

同一 Installation 不能同时连接两个 Workspace。Setup Callback 发现已归属其他 Workspace 时返回 Conflict，
不自动转移。

## 7. `audit_events`

| 列 | 类型 | 约束 |
|---|---|---|
| `id` | bigserial | PK |
| `workspace_id` | uuid | FK workspaces, cascade |
| `actor_user_id` | uuid | FK users, set null |
| `actor_kind` | text | anonymous/session/token/github |
| `action` | text | 稳定 dotted action |
| `resource_type` | text | workspace/member/token/installation/repository/share/session |
| `resource_id` | text | 外部 ID 或 UUID |
| `metadata_json` | jsonb | Secret-free allow-list |
| `created_at` | timestamptz | default now |

索引：`(workspace_id, created_at DESC, id DESC)`。Metadata 默认 `{}`，限制为 JSON Object。

## 8. 现有表变更

### `repositories`

- 为 `(workspace_id, id)` 增加 Unique，支持复合归属 FK/查询。
- `github_installation_id` 增加 FK -> `github_installations(installation_id)`，`ON DELETE SET NULL`。
- Private Repository 的 Installation 形状由 Import 事务强制；Installation 后续断开时允许字段置空，
  以保留已索引的历史读权，新 Clone/Update 会稳定失败为 Credential Missing。
- Provider Repo ID 存在时，增加部分唯一索引：
  `(workspace_id, provider, provider_repo_id) WHERE provider_repo_id IS NOT NULL`。

Migration 在添加 Private Constraint 前检查 v0.4 数据；旧版从未持久化 Private Repository，因此预期无冲突。

### `github_webhook_deliveries`

- `workspace_id uuid NULL` FK workspaces，用于审计和路由归属。
- Status 扩展为 `enqueued | ignored | synchronized`。
- 原有行保持 nullable Workspace。

### `share_reports`

- 增加 `(repository_id, visibility, created_at DESC)` 索引。
- 不修改现有 Visibility Enum；应用层在 v0.5 禁止 Private Repository 创建 Public/Unlisted。

## 9. 关键事务

### 首次登录

1. Upsert `users` by Identity；更新 Display Name/Avatar/Email。
2. Upsert `user_identities` by `(provider, provider_user_id)`。
3. 查找 Personal Workspace；不存在则使用稳定 Slug 后缀创建。
4. Insert Owner Membership。
5. Insert Session，Active Workspace 为 Personal Workspace。
6. Insert Login Audit。

任何一步失败整体回滚。

### 切换 Workspace

```sql
UPDATE auth_sessions s
SET active_workspace_id = $workspace
WHERE s.id = $session
  AND s.user_id = $user
  AND EXISTS (
    SELECT 1 FROM workspace_members m
    WHERE m.workspace_id = $workspace AND m.user_id = s.user_id
  )
  AND s.revoked_at IS NULL AND s.expires_at > now();
```

### Private Import

1. Lock Installation Row，验证 Workspace 与非 Suspended。
2. Upsert Repository，不允许已存 Provider Repo ID 跨 Workspace/Installation 被替换。
3. 创建 Snapshot/Job，Job 通过 Repository 间接获得 Installation ID。
4. Audit Import，不记录 Clone Credential。

## 10. Access Query 规则

Repository 可见条件：

```sql
WHERE r.id = $resource
  AND (
    r.workspace_id = $principal_workspace
    OR (
      r.workspace_id = PUBLIC_WORKSPACE_ID
      AND r.visibility = 'public'
    )
  )
```

Session/Token Principal 的 `$principal_workspace` 已在认证查询中验证 Membership。Snapshot/Job/PR/Share 通过 Join
Repository 复用同一条件。不允许先只按 UUID 读取详细行，再在应用层比对 Workspace。

## 11. Migration 验收

- 空库 0001 -> 0005。
- 真实 v0.4 Schema/Data -> 0005。
- Migration 二次运行 no-op。
- Session Active Workspace 跨 User Membership 被 FK 拒绝。
- 重复 GitHub Identity/Installation/Provider Repo 被 Unique 拒绝。
- Private Import 事务无 Installation 被应用层和 Integration Test 拒绝。
- 删除 Installation 只解除 Credential 映射，不删除 Repository/Snapshot 历史。
- 删除 Workspace 级联清理 Session/Token/Installation/Audit 和业务资源。

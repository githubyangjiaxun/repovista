# v1.3 数据库设计：通知 Endpoint 与 Outbox

## Migration 0010

### `workspace_notification_endpoints`

| 列 | 约束 | 说明 |
|---|---|---|
| `id` | UUID PK | Endpoint 身份 |
| `workspace_id` | Workspace FK/CASCADE | 租户边界 |
| `name` | 1–100 | 展示名称 |
| `url` | 1–2,048 | 出站 HTTPS 地址（生产） |
| `event_types` | JSON array | 订阅事件 |
| `enabled` | boolean | 暂停新投递 |
| `created_by` | User FK/SET NULL | 创建者摘要 |
| `created_at`/`updated_at` | timestamptz | 配置时间 |

签名秘密不在表中保存，由运行时 `NOTIFICATION_SIGNING_SECRET` + Endpoint ID 派生。

### `notification_deliveries`

| 列 | 约束 | 说明 |
|---|---|---|
| `id` | UUID PK | 投递身份 |
| `endpoint_id`/`workspace_id` | 复合 FK | 防止跨租户引用 |
| `event_type`/`event_key` | 唯一 Endpoint+key | 幂等 outbox |
| `payload_json` | JSON object | 不含备注正文/源码 |
| `status` | queued/running/succeeded/failed | 生命周期 |
| `attempt_count`/`max_attempts` | 有界整数 | 重试上限 |
| `next_attempt_at` | timestamptz | 退避时间 |
| `lease_owner`/`lease_expires_at` | 可空 | Worker 租约 |
| `last_status_code`/`last_error` | 有界 | 脱敏故障摘要 |
| `delivered_at`/`created_at`/`updated_at` | timestamptz | 时间线 |

## 事务不变量

1. Review upsert/clear、audit event 和匹配 Endpoint 的 outbox 行在同一数据库事务提交。
2. `event_key` 使用审计事件 ID，重复请求不会为同一 Endpoint 产生重复投递。
3. Claim 使用 `FOR UPDATE SKIP LOCKED`；租约过期的 running 行可被下一 Worker 接管。
4. 完成/失败更新必须匹配 lease owner；重试使用有界指数退避，最终状态不可自动回退。
5. Endpoint 删除级联待投递行；Workspace 删除级联全部配置和投递记录。

## 保留与隐私

投递历史保留事件身份和状态码，不保存请求响应正文、备注正文或源代码。下游错误只保留截断后的安全文本，
避免把可能包含敏感信息的响应扩散到 Workspace 审计面。

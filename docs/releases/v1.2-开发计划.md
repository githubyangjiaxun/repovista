# RepoVista v1.2 开发计划：Reviewable Guardrails

目标版本：`1.2.0`

v1.2 将确定性 Architecture Guardrails 扩展为可审阅的工程工作流。扫描算法仍然只由
Snapshot、Parser、Guardrail Profile 和固定版本算法决定；人类审阅只能附加状态、备注和审阅者
信息，不能改变 Finding、阈值、报告状态或 CI 退出码。

## 用户价值

- 维护者可以对每个 Finding 标记“已确认”“接受风险”或“误报”。
- 审阅备注与审阅者/时间被保存在 Workspace 隔离的数据库中，可用于交接和审计。
- SARIF/JSON 导出同时携带审阅元数据，消费者仍能单独读取确定性结果。
- 匿名 Bundled Demo 继续可读，但不能被匿名用户修改。

## 交付范围

1. 新增 `guardrail_reviews` 当前状态表和前向 Migration `0009`。
2. 共享 Contract、PostgreSQL Store、审计事件和 Workspace 隔离。
3. `GET/PUT/DELETE /v1/snapshots/:snapshotId/guardrails/reviews/:findingId` 工作流。
4. 带 `reviewStatus`、`reviewNote`、`reviewedAt`、`reviewedBy` 的确定性 SARIF；另提供稳定的
   JSON 导出。
5. Web Finding 卡片审阅控件和 Viewer 只读体验。
6. CLI `guardrails reviews list/set/clear`，支持文本和 `--json`。
7. OpenAPI、版本号、发布/安全/AI 边界文档和自动化测试。

## 非目标

- 不训练、调用或评价 AI 模型；人审状态不是模型质量标签。
- 不让审阅状态影响 `pass/warn/fail`、Finding 数量、SARIF `level` 或 CI 退出码。
- 不跨 Snapshot 自动复制审阅；每个 Snapshot 的 Finding 必须单独确认。
- 不为匿名 Demo 提供写权限。

## 完成定义

- Contract 对未知字段、非法状态和过长备注拒绝。
- 所有写入验证 Session CSRF、Workspace 角色/Token scope、当前 Snapshot Finding 身份，并追加审计事件。
- 私有资源响应 `Cache-Control: private, no-store`；公开资源不缓存用户私密信息。
- OpenAPI 与 Fastify 路由 100% 匹配，完整质量门禁和 CI 通过。
- 提交前执行 `git diff --check`、`git fsck --full`，且远端仓库保持 Private。

# RepoVista v0.6 开发计划

状态：设计完成，首个增量为 Architecture Guardrails（2026-08-23）
目标版本：`0.6.0`

## 1. 版本主题

v0.6 为 RepoVista 增加“可解释的架构质量门禁”。系统在不可变 Snapshot 上运行一组确定性规则，
发现循环依赖、超大文件/符号、过高扇入、未解析导入和解析失败，并为每个发现返回固定 Commit、
路径、行号和规则指标。报告可以直接用于代码评审、CI 和团队架构讨论。

AI 不参与规则判定，也不替代证据。未来可选的 AI 解释只能读取本次报告已经验证的 Finding，
不得凭空生成问题或引用其他 Commit。

## 2. 用户价值

1. 新成员可以先看“架构风险地图”，再决定从哪里阅读代码。
2. 维护者可以把 SARIF 报告接入 GitHub Code Scanning 或其他 CI 平台。
3. 规则阈值、算法版本和 Snapshot 身份都显示在结果中，别人能够复现结果。
4. 公共和私有仓库复用同一套权限边界；私有源码不会因报告导出变成匿名资源。

## 3. 首个交付范围

### 3.1 确定性规则

默认 profile 固定如下（实现中不可由模型或请求任意改变）：

| 规则 | 默认阈值 | 默认级别 | 含义 |
|---|---:|---|---|
| `dependency_cycle` | 环长度 2–12 | error | 包级 imports 图存在有向环 |
| `large_file` | >800 行或 >100 KiB | warning | 单文件维护成本过高 |
| `large_symbol` | >150 行 | warning | 单个函数/类/方法/类型跨度过大 |
| `high_fan_in` | 入边 >=20 | warning | 符号成为高耦合变更热点 |
| `unresolved_import` | 每条 | info | 导入目标未能在 Snapshot 内解析 |
| `parse_failure` | 每个非 parsed 文件 | warning | 解析缺口可能影响图的完整性 |

规则只读取 Snapshot Graph Data；忽略 `contains` 边产生的扇入，循环只使用已解析的 `imports`
边。所有结果按规则、路径、行号、稳定 ID 排序。

### 3.2 HTTP API

- `GET /v1/snapshots/{snapshotId}/guardrails`：返回 JSON `GuardrailReport`。
- `GET /v1/snapshots/{snapshotId}/guardrails/sarif`：返回 SARIF 2.1.0 下载体。

两个接口都先执行 Snapshot Workspace Access Check；无权资源统一返回 404。私有报告使用
`Cache-Control: private, no-store`，公开报告使用可重新验证的公共缓存策略。

### 3.3 CLI 与 Web

- CLI：`repovista guardrails <snapshot-id>`，默认人类可读摘要，`--json` 输出完整报告，
  `--sarif <file>` 写入 SARIF；发现 error 时返回退出码 2。
- Web：Repository Workspace 增加 Guardrails 页面，显示总览、阈值、Finding 列表和固定证据链接；
  可下载 SARIF，不显示私有源码正文。

## 4. 非目标

- 不执行仓库脚本、不运行编译器或外部静态分析器。
- 不把 Finding 持久化为可变状态；报告始终从指定 Snapshot 重算。
- 不在本版本自动修改代码、创建 PR 或阻断 Webhook。
- 不宣称规则等价于完整安全扫描或业务正确性证明。

## 5. 完成定义

- Guardrails 纯函数在相同 Snapshot 输入下字节级稳定。
- 每个 Finding 至少有一条可导航的源码/关系证据；没有证据的 Finding 不输出。
- API、CLI、Web 对 public/private、跨 Workspace、Viewer/Editor 的行为与既有矩阵一致。
- SARIF 可被标准 JSON 解析器读取，`ruleId`、`level`、`uri` 和行号与 JSON 报告一致。
- OpenAPI、README、CHANGELOG、Roadmap、前后端/运维文档同步。
- 新增单元、API、CLI、Web 测试，并通过现有全量质量门禁。

## 6. 实现阶段

1. Contracts 与 `@repovista/guardrails` 纯函数、固定规则和测试。
2. API 路由、SARIF 导出、错误/缓存头、OpenAPI。
3. CLI 命令和退出码、文件写入安全约束。
4. Web Guardrails 面板、证据跳转和下载。
5. 版本/文档/验收记录、全量门禁、独立 Git 提交和 Push。

## 文档维护规则

- 文档中的接口、表名和事件名必须与代码保持一致。
- 每次破坏性变更都要更新对应文档和 CHANGELOG.md。
- 方案仍在讨论时标记为 proposal，落地后补充决策日期。
- 文档中的性能目标不是承诺，必须通过 Benchmark 验证后才能对外宣传。
